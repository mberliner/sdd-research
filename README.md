# SDD Research Hub

Proyecto independiente para investigar Spec-Driven Development (SDD) en dos lineas separadas:

1. Proyectos de docs e investigacion.
2. Proyectos de software.

Fecha de inicio: 2026-03-01.

## Por que separar lineas
SDD no se aplica igual en ambos contextos.

- En docs/investigacion, el foco principal es consistencia semantica, trazabilidad de fuentes y calidad argumental.
- En software, el foco principal es comportamiento correcto, seguridad, confiabilidad y entrega continua.
